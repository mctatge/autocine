    Local MCP server

    Let the model edit the take, not guess at the timeline.

    AutoCine exposes the same non-destructive engine used by its editor through standard MCP. Any compatible client can inspect structured activity, locate spoken phrases, write an edit and look at the rendered result before export.

    1. 01 Orient describe_session

      Read beats and existing edits before requesting individual frames.

    2. 02 Locate find_in_transcript

      Resolve what was said to a source timestamp instead of guessing.

    3. 03 Edit add_cut · adjust_zoom

      Write explicit, reversible decisions to the project's edit spec.

    4. 04 Verify preview_frame · render_video

      See the real renderer's output, self-correct, then export.

    Know the boundary. AutoCine stores source recordings and edit specs on your Mac and does not upload them itself. A connected MCP client may send returned transcript excerpts, metadata or preview frames to its configured model provider. That transfer follows the client's data controls.
